生辰录 隐私政策

生效日期：2026年6月10日  |  Version 1.0

欢迎使用生辰录！我们深知个人信息对您的重要性，并将按照法律法规的规定，保护您的个人信息及隐私安全。生辰录是一款非焦虑型生命感知与生活沉淀工具，我们的核心隐私承诺是：

🛡️ 本地优先 · 最小化收集 · 匿名可用
您的核心数据（生辰、感悟、照片）默认仅存在于您的设备本地，采用AES-256加密；您可以完全不注册账号、不提供手机号即可使用全部核心功能；我们绝不向您推送任何商业营销广告。

一、我们收集的信息

我们仅会收集实现产品核心功能所必需的最少信息，且大部分敏感数据默认仅在您的设备本地处理。

1.1 您主动提供的信息

  • 生辰信息：出生日期与时间（支持公历/农历）。该信息默认仅存储在您的本地设备中并经AES-256加密，绝不主动上传至我们的服务器，仅用于为您生成精确的生辰时钟与人生进度可视化。
  • 人生感悟与日记：您在发呆思考区或光影人生中主动输入的文字。默认仅保存在您的本地设备。
  • 照片与视频素材：您上传用于生成光影人生海报/视频的媒体文件。原始文件仅保存在您的本地设备。
  • 紧急联系人信息（独居安全功能）：如您主动设置，需提供联系人姓名、手机号、关系。该信息本地AES-256加密存储，仅在触发超时预警时通过第三方短信服务发送提醒。

1.2 我们自动收集的信息

  • 设备与日志信息：为保障App稳定运行、优化计时精度，我们可能会收集设备型号、操作系统版本、应用崩溃日志等基础非个人设备信息。此类数据不包含设备唯一硬件标识符（如IMEI/MAC地址）。
  • 匿名化行为统计数据：如发呆总时长、生成作品数、目标完成数等。该数据仅用于在您的设备端生成"个人生活成长报告"，不包含任何可识别您身份的信息，不上传至服务器。

⛔ 我们不强制要求您注册账号或提供手机号，您可完全匿名使用核心功能。

⛔ 我们不收集您的通讯录、精确地理位置、设备唯一硬件标识符等非必要权限。

⛔ 我们不向任何第三方出售、出租或交易您的个人信息。

二、我们如何使用信息

我们仅将上述必要信息用于以下核心目的，绝不用于任何商业营销或焦虑贩卖：

  1. 核心功能实现：为您提供生辰秒级时钟、人生剩余意义规划、发呆治愈引导、光影人生内容生成、独居安全预警等服务。
  2. 本地体验优化：基于本地行为数据为您生成个性化成长轨迹与报告。
  3. 稳定性保障：通过匿名崩溃日志修复Bug，优化计时引擎的低功耗运行。

三、我们如何存储与保护信息

3.1 本地优先存储策略

您的生辰信息、感悟文字、照片视频等高度敏感数据，默认采用AES-256加密算法存储在您的本地设备中。应用核心计时、规划、发呆、签到功能100%支持离线使用，无需网络连接即可正常运行。

3.2 可选的云端备份（端到端加密）

如您希望在不同设备间同步数据，可手动授权开启"云端加密备份"。

  • 开启后，数据将采用端到端加密（TLS 1.3传输 + 服务器不可解密）存储于云端。
  • 加密密钥仅保存在您的本地设备，我们及任何第三方均无法查看您的备份数据内容。

3.3 数据存储地域

  • 中国大陆用户：云端备份数据存储于中华人民共和国境内的云服务器，符合《个人信息保护法》《数据安全法》要求。
  • 海外用户（Google Play版）：云端备份数据存储于用户就近区域的云服务器，符合GDPR/CCPA要求。

四、我们如何共享、转让与公开披露信息

除以下情形外，我们绝不共享、转让或公开披露您的个人信息：

  1. 您主动分享：您将生成的光影人生海报、视频或人生进度截图，主动分享至第三方社交平台时，相关内容由您自主控制。
  2. 紧急联系人预警：如您开启"紧急联系人预警"功能，当您超时（24/48/72小时，可自选）未签到时，系统将通过第三方短信服务向您预设的联系人发送预警短信。预警短信仅包含基础提醒信息，绝不暴露您的详细地理位置或生辰数据。
  3. 第三方服务提供商：我们可能委托第三方提供服务（如崩溃日志收集、云存储），但我们仅提供必要数据，并要求其遵守同等保密义务。
  4. 法律法规要求：根据相关法律法规、法律程序或政府部门的强制性要求。

📌 关于广告：生辰录不含任何开屏广告、信息流广告及强制性弹窗。所有推送内容均为正向治愈型（如"您已连续记录一周感悟"），严禁营销广告。我们不会将您的个人信息用于广告定向投放。

七、您的权利

我们在产品设计中为您提供了充分的控制权：

  1. 匿名使用权：您有权拒绝注册账号，直接匿名使用全部核心功能。
  2. 信息修改权：您可随时在App个人中心修改您的生辰信息及相关设置，修改后所有相关数据实时重新计算。
  3. 数据导出权：在设置中，您有权一键导出所有您输入的本地个人数据（支持JSON格式）。
  4. 彻底删除权：我们为您提供"一键清空所有本地数据"功能。点击后，将彻底且不可恢复地清除您在设备上的所有记录。若您已开启云端备份，删除操作也将同步触发云端数据的永久抹除。
  5. 推送控制权：所有推送默认关闭，您可自定义推送频率为"每日"、"每周"或"完全关闭"。
  6. 欧盟/加州用户特别权利：根据GDPR/CCPA，您享有数据访问权、更正权、删除权（被遗忘权）、数据可携带权、拒绝自动化决策权。您可通过下方联系方式行使上述权利。

八、未成年人保护

生辰录主要面向25-45岁核心群体与18-24岁次要群体。我们不会主动收集未成年人的个人信息。若您是未满18周岁的未成年人，请在监护人指导下使用本产品。如果我们发现在未获监护人同意的情况下收集了未成年人的个人信息，将立即设法删除相关数据。
